Jetty MCP

The hosted Model Context Protocol server for Jetty. Deploy, run, schedule and inspect runbooks from any MCP client, with nothing to install.

Endpoint
https://mcp.jetty.bot/mcp
Transport
Streamable HTTP, stateless (no sessions, JSON responses)
Auth
Authorization: Bearer <Jetty API key> — how to get a key
Metadata
/.well-known/oauth-protected-resource/mcp
Source
jetty-mcp-server (the same tools as the local npx server)

Claude Code

claude mcp add --transport http jetty https://mcp.jetty.bot/mcp \
  --header "Authorization: Bearer mlc_…"

Cursor, VS Code, Windsurf and other JSON configs

{
  "mcpServers": {
    "jetty": {
      "url": "https://mcp.jetty.bot/mcp",
      "headers": { "Authorization": "Bearer mlc_…" }
    }
  }
}

curl

curl -sS https://mcp.jetty.bot/mcp \
  -H "Authorization: Bearer mlc_…" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
Requests are scoped to the key's collection. Clients that can only sign in with OAuth (for example the Claude.ai and ChatGPT connector galleries) are not supported yet; use a client that sends an Authorization header.
